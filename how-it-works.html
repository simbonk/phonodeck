4Lore that keeps living

  • Every lore entry has a stable id. When the memory pass sees an entry change in play (a relationship, a secret revealed), it rewrites the description and keeps the last four versions in the World tab.
  • A stranger is stored under their real name but shown only by their role ("the old man") until the story says the name. Then the same entry is revealed, with no duplicate.
  • An entry you edit by hand is pinned into every prompt as a player-set fact (up to 30, newest first) and wins over earlier narration and recalled memories. The memory pass still adds what happens to it in play, but never changes the name, type or role you wrote, and your own words travel alongside the updated description so later rewrites cannot wear your correction away. An edit you make while the memory pass is running is kept.
  • Undo restores the transcript and all of this memory to how it was before the turn.

5Which model does what

ModelUsed for
Gemini ProThe Game Master's replies, the Architect, the photo reader and the report card. Thinking effort is Low by default.
Gemini FlashThe memory pass, dictation cleanup, bible rewrites, GM secrets, chapter summaries and set-up suggestions. Falls back to Pro if Flash is out of quota.
Gemini embeddingMeaning search in recall. Vectors are made in the background and saved with the story.
Gemini voice (TTS)The narrator. The device's own voice takes over if Gemini's voice is unavailable or out of quota.

Everything runs in the browser with your own key. The only server is the optional invite proxy, which forwards a guest's calls with the host's key and counts what each costs.
